## 📖 About the Project

Career-Compass is a machine learning-driven decision-support tool designed to help engineering students make data-backed career choices. Instead of relying on anecdotal advice or static listicles, the system synthesizes real-world job postings, compensation trends, and layoff signals to generate personalized, evidence-grounded recommendations.

By inputting their current skill set, a target company, and salary expectations, users receive an actionable roadmap to navigate the shifting tech job market.

## ✨ Key Features

*   **Market Trend Analysis:** Evaluates the hiring health of a target company (growing, stable, or contracting) using recent posting volumes and layoff signals.
*   **Intelligent Company Shortlisting:** Provides a ranked list of comparable or better-fit companies, scored by skill match, compensation alignment, and hiring trends.
*   **Salary Prediction:** Calculates a realistic salary band for the specific skill set and target role.
*   **Prioritized Skill-Gap Identification:** Recommends exactly which skills to acquire, ranked by current market demand and frequency in active job postings.
